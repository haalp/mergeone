# Code of Conduct

mergeone follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, argue with evidence, and keep disagreements about the work. Harassment,
discrimination, and personal attacks are not tolerated anywhere in this project's spaces (issues, pull requests,
discussions, the website).

Two project-specific norms, because this is a benchmark as much as a product:

- **Results are not personal.** A negative result, a failed hypothesis, or a model that did not meet the bar is
  reported the same way as a success. Do not pressure anyone to soften, hide, or reframe a number.
- **Pre-registration is binding.** Changing a threshold after seeing the test split is a conduct issue, not a
  technical one. Log deviations in `CHANGELOG.md`; do not rewrite `PROTOCOL.md` history.

Report conduct problems privately to the maintainer via GitHub (profile → email) or by opening a private
security advisory on this repository. Reports are handled confidentially. Consequences follow the
Contributor Covenant's enforcement guidelines: correction, warning, temporary ban, permanent ban.
